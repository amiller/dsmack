# Security reports

dsmack is a prototype. README.md lists what it does not protect against;
reports about those limits are welcome but are not vulnerabilities.

Use **Report a vulnerability** in this repository's Security tab to contact the
maintainer privately. If it is unavailable, open an issue asking for a private
channel without disclosing details.

Include the affected revision, component, expected behavior, a minimal
sanitized reproduction and impact. Never post signing keys, provider
credentials or private traces in public issues.
