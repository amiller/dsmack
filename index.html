A network of ordinary Macs

Join the network

Your Mac joins a network that proves what code it runs. About five minutes, no terminal. Each Mac shows the others Apple's attestation of the program it is running, and the ones running an admitted build share one key.

  1. 1Download Dsmack Node and extract the ZIP.
  2. 2Open it and accept the normal macOS prompt. It says You’re in. once it holds the key.
  3. 3Choose Share in public node directory… and find your node on the map.

What it is, and what it is not

What it is

  • An app anyone can build. The source is public. Anyone with an Apple Developer account can build Dsmack Node and sign it themselves. Build instructions.
  • The network admits the code, not the signer. A Mac joins by showing Apple's attestation of the build it runs. If that build's measurement is on the admitted list, it is in. Who signed it does not matter.
  • One shared key. Every admitted node holds the same key. It only moves from one admitted node to another, sealed to the receiver. One compromised node exposes it.
  • A testnet. It runs on Base Sepolia. Joining helps show the admission check works on Macs nobody here controls. Nothing is earned yet; the participation receipt has no monetary value.

What it is not

  • A cloud you rent. The Macs belong to the people running them, on their own desks and shelves.
  • Free of operators. Operators can still refuse service, delay or drop requests, and stop the seeds. Whoever holds the registry key decides which builds are admitted next, and that change is public on chain.
  • Anonymous. Dsmack does not hide your IP address. Node details.

    Redeem a coupon

    Abalone is the companion app for coupons. A coupon gets you an API key for private inference. The key is made inside an admitted node and sealed to you, so the operators never see it.

    Open the gift link, let your agent install Abalone and redeem it, then open a fresh terminal. You do not need to run a node for this.
