Earlier shared-key node directory

This directory belongs to the Node 0.3.0 shared-key experiment. It reads that experiment’s Base Sepolia registry and relay, when available. A listed node is a participant in the earlier key-sharing network. For current task attempts, checks and payments, open the bounty dashboard.

The page refreshes its registry and relay observations every 30 seconds. A check-in older than 90 seconds is stale. Source status appears below. · Registry on Blockscout

Online means the relay verified a signed check-in within 90 seconds. Admitted means the observed app build meets the registry’s current code policy. Key epoch identifies the shared-key generation reported by the node. These fields describe a check-in and key-sharing state; they do not reserve a runner or report a completed task.

Check-ins are opt-in. The relay verifies each App Attest assertion and receipt; this page displays its report. Members without a check-in show their last registry event instead.

The table lists members with a relay check-in still in the directory or a registry event in the last 24 hours; the button shows every member ever registered. "Online" is a verified relay check-in under 90 seconds old. Joining the registry requires an App Attest attestation; any Apple team may join, so it does not identify who runs the node. "Admitted" reads the CDHash of the member's last App Attest assertion from its category's adapter; for the measured category it is admitted while the measurement registry has an open window for that build's M, its signer-independent code measurement, at the current block.
