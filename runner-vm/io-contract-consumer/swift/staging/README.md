Run `bash run_staging_fault.sh` on macOS. This compiles the exact production staging helper extracted from V2Launch.swift, with boundary instrumentation and shim dependencies. It does not launch a VM, sign, use credentials, or replace cleanup decisions. Controls inject partial-copy cancellation, size/digest/read-back mismatch, read-back throw and fsync failure. Foreign replacement must survive before and after deferred cleanup, all owned FDs must close, original refusal must propagate, possible residue must be registered and emitted as JSON, and residue-free policy must refuse. Fixtures are retained deliberately. Baseline reproduction is retained separately in the lane evidence.
